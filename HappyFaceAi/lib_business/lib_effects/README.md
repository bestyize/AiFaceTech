# lib_effects：猫脸惊喜图层

独立 Kotlin Multiplatform 模块，包含纯数据的 EffectScene / EffectController，以及透明 Canvas + emoji 图层。没有相机、麦克风、模型或网络依赖；没有额外动画引擎或图片资产。

## 第一版

| 效果 | 演出 | 自动触发 | 时长 |
| --- | --- | --- | --- |
| Fireworks | 两侧火箭升起、错时绽放、少量彩纸落下 | 确认 V 字；确认“成功了”等好消息 | 3.6 秒 |
| Hearts | 爱心从两侧依次探出、摆动、上浮渐隐 | 确认夸奖；抚摸按钮 | 3 秒 |
| RainToSun | 云和细雨渐退，太阳与星光出现 | 确认的难过话语 | 5.6 秒 |
| StarReward | 金色星光、扩散细环和短暂碎星 | 确认点赞 | 2.2 秒 |

原有猫脸参数继续生效，特效位于猫脸上层、HUD 和语音控件下层，不处理点击。雨景不由视觉的一帧难过分类或中间转写触发。

## 触发与生命周期

行为模块发出纯数据 BehaviorEffectIntent；shared 将其转换为场景请求。每个请求有独立 instanceId。控制器保留最近 32 个已消费 ID，重复 ID、不合法时间、过期请求、被关闭功能丢弃的请求不会补播。

最多一个主要场景；同一场景正在播放时的新请求合并为当前播放，不重新计时。低优先级事件丢弃，更高或相同优先级的新场景可以替换；不排队。优先级沿用确认行为的来源，手动预览可以直接替换。

离开猫脸页、后台、取消语音互动或关闭特效时清理场景。预览打开时暂停猫脸页相机/推理和被遮住的猫脸动画，预览自己的动画与控制器。所有图层生命周期由宿主控制。

确认文字到达时可播放相应特效，思考、倾听和说话期间将透明度降低到约三分之一，并减少粒子数；没有按实际音频节拍或口型同步。屏幕保护区避让眼嘴、右上相机入口和底部语音控件，眼嘴区跟随语音模式的猫脸上移。

## 性能与符号

每个活动特效最多约 30fps，效果为空/过期时不启动动画循环。种子、粒子随机描述和爱心路径按场景缓存，emoji 文字布局缓存；时间只在 Canvas 绘制阶段读取。烟花最多 84 条粒子射线加 18 个碎点，雨滴 64 条，爱心 7 个；对话状态进一步减量。

emoji 使用完整字符串 💛 / ✨ / ☁️ / ☀️。显示风格随平台字体变化；关闭“使用 emoji 符号”后使用自绘形状。第一版验证了 Android 编译和桌面图形输出，iOS 尚需 Xcode / 实机验收，持续帧耗时与温升还需目标设备量测。

## 使用与验证

猫脸页轻点显示操作层，点击“特效”进入全屏预览。可以立即保存开关、强度和符号偏好，单独播放四个效果或停止；返回后恢复感知。

```text
gradlew.bat :lib_business:lib_effects:jvmTest :lib_business:lib_behavior:jvmTest :shared:jvmTest :androidApp:assembleDebug
gradlew.bat :desktopApp:exportFaceEffects
```

exportFaceEffects 导出两种尺寸、四个效果、四个时刻以及无 emoji 版本，加上四种预览尺寸，共 44 张图片。交互检查通过实际滚动访问开关、播放、停止、返回按钮，不请求模型或启动音视频设备。
