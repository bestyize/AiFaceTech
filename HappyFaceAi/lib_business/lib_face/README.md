# lib_face · 机器人脸部表情系统

猫脸渲染与表情动画的独立 Kotlin Multiplatform 库。Android / iOS / Desktop 共用同一套参数与渲染代码，
宿主 App 只需要调用 `FaceStage(...)` 或 `rememberAnimatedFace(...)`。

## 模块结构

```
lib_business/lib_face/src/commonMain/kotlin/com/aifacemate/face/
├── model/     表情编号、渲染参数、表情库、参数校验
├── anim/      过渡混合、眨眼、呼吸等纯函数与动画状态机
├── render/    几何布局、矢量图形、Canvas 渲染器
└── ui/        动画宿主 FaceStage 与调试台 FacePreviewScreen
```

设计原则：**渲染器不认识表情编号，表情库不认识画布尺寸**。
新增表情 = 在 `ExpressionLibrary` 里加一条参数，不需要改渲染代码。

## 当前状态（Alpha 1）

- 100 个表情位全部有参数（基础 01-25 / 扩展 I 26-50 / 扩展 II 51-75 / 扩展 III 76-100），其中 5 个已按设计图精修并冻结：Idle / Happy / Curious / Sleeping / Greeting
- 扩展 III（76-100）已按 `assets/表情76-100.png` 逐格校准眼型、嘴型、高光、腮红、手势与符号位置
- 图元库覆盖：圆环眼、高光大眼、侧视眼、下垂泪滴眼、依赖大眼、弧形眼、下垂闭眼、半睁眼、折线眼 ＞＜、环内金色五角星眼、爱心眼、星星眼、螺旋眼、叉叉眼；猫嘴、微笑、张嘴吐舌、大张嘴、波浪嘴；灯泡、盾牌、锁、点赞、猫爪、云朵、温度计、四角扫描框、转圈、进度条、彩带、红叉、爆发线、时钟、音符、电池、太阳、玫瑰等情绪符号
- 两种渲染表面：`DEVICE_SCREEN`（实机 4.0 英寸 16:9 屏铺满，只有脸）与 `PRODUCT_MOCKUP`（整机概念图，带发光耳朵与外壳）
- 屏幕底色按表面区分：**实机屏幕是纯黑**（App 画什么像素屏上就是什么），玻璃渐变与顶部高光只出现在概念图里
- 渲染开关：**扩散光晕**（`DEFAULT_DIFFUSE_GLOW`，只控制最外层的大面积辉光，近边发光始终保留）；状态提升到 `App`，调试台与实机全屏共用同一份
- 耳朵灯不做开关：走查时始终亮着，作为表情的背景光
- 待机生命感：随机间隔眨眼（2.4s ~ 6.4s）+ 呼吸起伏；弧形眼表情不参与眨眼
- 表情切换：420ms 缓入缓出过渡，数值参数插值、眼型/嘴型过半切换、情绪符号淡入淡出
- 全部图形为矢量绘制，不依赖图片与字体，可等比渲染到 4 英寸屏幕或任意预览窗口

## 常用命令

```bash
./gradlew :lib_business:lib_face:jvmTest                 # 逻辑层测试（参数、动画、布局）
./gradlew :desktopApp:run                   # 打开调试台，实时切换表情
./gradlew :desktopApp:exportFaceSheets      # 离屏导出 100 张表情图 + 总览 / 对比 / 实机全屏走查图
./gradlew :androidApp:assembleDebug         # 打包 Android 原型
```

导出的图片在 `desktopApp/build/face-sheets/`，可直接与 `assets/04_伴侣机器人表情系统.png` 对照走查。
- `_overview-01-25 / -26-50 / -51-75 / -76-100` 与四张设计图一一对应；同名 `-nodiffuse` 是关掉扩散光晕的版本
- `_compare-diffuse` / `_compare-diffuse-levels` 用来挑扩散光晕档位（1.0 / 0.6 / 0.3 / 0）
- `_device-sheet` / `_device-sheet-nodiffuse` 走的是实机全屏组件本身，用来确认全屏时看到的效果

## 调试台布局

`FacePreviewScreen` 默认全屏预览，右上角菜单展开约 98% 不透明的全屏功能区，无标题栏。
列表开头为默认收起的“显示设置” section，明确标注“展开 / 收起”，展开后显示生命感、扩散光晕与渲染表面；下方始终保留 100 个表情位（四组，每组 25 个）。
左上返回箭头与右上关闭图标均为 32dp 悬浮控件，右下角不再放切换控件，不设顶栏或底栏，内容区铺满浮层。选项不为悬浮按钮缩窄首排，表情采用等宽网格，按屏宽自动分列，小屏为 40dp 高、大屏为 48dp 高；大屏内容限制 880dp 并居中，选中项为暖黄色；选择后自动收起。

`gradlew.bat :desktopApp:exportFaceMenus` 导出五种尺寸的预览与菜单，检查全屏尺寸、全部表情、实际滚动、开关、返回及菜单收起。

## 实机形态与调试入口

真机上跑的是 `FaceDisplay`：整块屏只显示一张猫脸，没有控件、没有标题、没有外壳。
耳朵、侧灯环是机身上的硬件灯效，**不在屏幕里**，因此 `DEVICE_SCREEN` 下不绘制耳朵，
表情参数里的 `earGlow` 在实机屏幕上不生效（有测试锁住这个产品决定）。

调试入口：**在实机全屏界面长按屏幕**进入 `FacePreviewScreen`，可以切表情、走查 100 个表情位、
在「整机概念图 / 实机屏幕」两种渲染表面之间切换、开关扩散光晕；点「返回上一页」返回生命中心，
开关状态会一起带回去（不会出现"预览关了、全屏还有"）。
