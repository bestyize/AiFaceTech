# lib_behavior：行为与表情决策

跨平台规则核心，消费 `BehaviorEvent`，输出 `BehaviorState`。只依赖表情模块；不采集音视频、不请求模型，也不持有 Compose 状态。宿主使用同一单调时钟调用 `accept(event, nowMillis)` 和 `state(nowMillis)`，并在同一线程串行调用。输出包含表情、交互阶段、触发原因和临时反应结束时间。

## 第一版规则

| 输入 | 输出 | 持续时间 / 冷却 |
| --- | --- | --- |
| 倾听 / 处理中 / 播放 | LISTENING / THINKING / SPEAKING | 随语音流程切换 |
| 抚摸按钮 | HAPPY | 2.4 秒 / 0.5 秒 |
| “真可爱”“你很棒”“喜欢你”等 | BASHFUL_SMILE | 8 秒 / 1 秒 |
| “难过”“伤心”“不开心”等 | COMFORTING | 8 秒 / 1 秒 |
| “你好”等 | GREETING | 8 秒 / 1 秒；回复结束后显示 2.4 秒 |
| 人进入画面 | GREETING | 2.4 秒 / 5 秒 |
| 静态点赞手势 | APPROVING | 2.4 秒 / 2 秒 |
| 张开手掌 / V 字 | GREETING / CELEBRATING | 2.4 秒 / 2 秒 |
| 握拳 / 指向 / 捏合 | PLAYFUL / CURIOUS / WINK | 2.4 秒 / 2 秒 |
| 微笑 / 难过外观 / 惊讶外观 | HAPPY / COMFORTING / CURIOUS | 2.4 秒 / 3 秒 |
| 感谢 / 道歉 / 好消息 / 晚安 | GRATEFUL / REASSURED / HAPPY / GOOD_NIGHT | 确认文字后暂存，回复结束显示 2.4 秒 |

语音阶段优先于临时反应；临时反应依次为抚摸、话语、手势、人出现、面部外观。倾听阶段允许当前话语的中间转写改变表情，修订为中性或否定内容后撤销；思考与播放阶段保持对应状态。确认后的内容反应最多暂存 60 秒，回答结束后显示 2.4 秒；取消时清理，不补播。临时反应到期后恢复用户选择的基础表情。视觉只在待机时触发，不打断当前对话，不排队补播。离开陪伴页或关闭对话会清理当前交互。

视觉输入至少连续三个不同时间标记的有效帧才确认。超过一秒的旧结果、重复或乱序结果、未来时间标记被忽略。人和手势分别记录时间顺序：事件中 null 表示该流没有分析此任务，不表示目标消失。手势间隔超过 1.5 秒、人检测间隔超过 2.5 秒时清理对应的连续证据。人消失两秒后可重新迎接（仍受冷却限制）；持续点赞不会重复触发，必须先松开再确认。

冷却期或抚摸反应阻止视觉回应时，不会标记为已回应。松手后再次点赞即使早于冷却结束，只要后续有效帧仍确认该动作，冷却结束即可回应；成功回应后持续保持同一个手势仍不会重复触发。

## 应用接入

主动对话策略独立在 `behavior.proactive`：持续微笑可触发固定提问，经 TTS 播放完成后自动倾听。开场冷却在主动对话设置中调整，默认 15 秒、范围 5–120 秒，与同一段微笑仅一次规则一起控制触发，不受普通表情回应的 3 秒冷却控制。配置与闭环边界见 [PROACTIVE_CONVERSATION.md](../../docs/PROACTIVE_CONVERSATION.md)。

`shared/App.kt` 持有控制器，用 50ms 时钟更新到期状态。`VoiceConversationOverlay` 转发阶段和已提交的用户文字（包括最终实时语音转写）；`LivingPerception` 在陪伴页订阅相机和感知结果，在工作线程推理、主线程提交事件。关闭页面或应用进入后台会停止感知并释放相机。

视觉沿用已有设置，至少一项已开启且模型可用时才启动相机；不会自动开启任务或下载模型。猫脸页直接消费感知任务按设置阈值过滤后的结果，不额外将手势或目标检测阈值提高到 0.7。几何手势分类器本身仍要求手部置信度至少 0.55。模型缺失时请先到视觉设置下载。相机权限被拒绝或运行失败时显示提示，语音与手动表情仍可使用。

陪伴页将手势/表情与重型 YOLO 拆成独立感知会话：前者每轮完成后休息 350ms，YOLO 每轮后休息 1500ms。只有未开启表情识别时，目标流提供有人出现的证据，避免两条流互相覆盖。Android 的每个 ONNX Session 限制为两个算子内线程、一个算子间线程，并关闭线程池空转；当前仍使用 CPU / FP32，没有启用 GPU 或 NPU。相机预览页保留原来的任务汇总与 150ms 间隔，也使用新的 Android 线程配置。

轻点猫脸后的操作层显示视觉监测状态。相机报告错误时三秒后自动重启，运行中超过八秒没有新帧也会重启，不需要进入相机预览页。拒绝权限时不自动重复请求，进入系统设置授权后返回应用可重启感知。

文字规则只匹配少量明确词组并排除明确的否定词组，不理解复杂否定、讽刺或复杂上下文；不把视觉表情分类当成用户真实情绪。音量仅驱动最多 2% 的面部活动并在 400ms 内衰减，不判断情绪。本版不包含声音语气识别、长期人格、模型表情建议或音频口型。语音播放期间仍展示统一 SPEAKING，口型与情绪叠加属于后续工作。语音方案与支持边界见 [VOICE_INTERACTION_PLAN.md](../../docs/VOICE_INTERACTION_PLAN.md)。

## 验证

```text
gradlew.bat :lib_business:lib_behavior:jvmTest :lib_business:lib_vision:jvmTest :shared:jvmTest :androidApp:assembleDebug
```

规则测试覆盖阶段优先级、反应到期、基础表情恢复、视觉连续确认、重复与过期结果、冷却与重入、对话期间的视觉抑制及交互清理。相机、麦克风和目标设备的推理耗时需要实机验收；iOS 需要 macOS / Xcode 构建验证。
