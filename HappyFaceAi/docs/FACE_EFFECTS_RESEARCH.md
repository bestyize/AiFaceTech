# 猫脸惊喜特效：调研与设计建议

调研日期：2026-10-01。本文件记录实现前的研究与设计建议；当前第一版已落地四个效果，实际接口、触发和验收范围见 [lib_effects README](../lib_business/lib_effects/README.md)。

## 结论

建议新增 `lib_business:lib_effects`，通过透明图层叠在猫脸上，第一版采用原生 Canvas 粒子与少量 emoji / 文字符号组合。保留现有矢量猫脸作为主角；让效果有出现、互动、收尾三个阶段，并与当前场景一致。

当前 `lib_face` 已有 FaceMark（星光、爱心、彩带等）和位置参数，但它们主要跟随表情参数显示。新模块负责独立时间轴、粒子运动、符号漂浮、播放请求和资源释放，避免把一整套特效调度塞进猫脸渲染器。

现有 `FaceDisplay` 绘制纯黑底，因此第一版建议的顺序是：纯黑底 / 猫脸 → 透明特效层 → 语音控件 / HUD / 相机按钮 / 提示。若后续增加猫脸后方的氛围层，需要重新分配黑底的绘制责任，否则背景效果会被覆盖。

## 技术路线比较

| 方式 | 适合的效果 | 本项目建议 |
| --- | --- | --- |
| Compose Canvas 粒子 | 烟花、雨滴、彩纸、流星、气泡 | 第一版主实现；可共用 KMP 物理和绘制逻辑，动态控制密度、颜色与位置 |
| emoji / 文字符号 | 💛、✨、🎉、☁️、🎵、星号、爱心 | 第一版符号实现；少量独立漂浮实例，支持缩放、旋转和淡入淡出 |
| Lottie / Compottie | 美术制作的完整小动画，如礼物打开、花朵生长 | 第二阶段按需引入；需要验证具体资源特性及与项目 Compose 1.12 / Kotlin 2.4 的兼容性 |
| Shader | 雨玻璃、雾气、光波、液体 | 后续高级提供者；Android AGSL 需要 Android 13+，项目 minSdk 为 24，需要平台实现与回退 |
| Rive | 复杂角色互动、状态机资源 | 暂不作为第一版依赖；现有猫脸已经是代码渲染，需评估新增制作工具与运行时接入的收益 |

Compose 支持控制绘制顺序和缓存绘图对象，可在绘制阶段读取高频动画状态，避免带动整页重组。[绘图修饰符](https://developer.android.com/develop/ui/compose/graphics/draw/modifiers)、[性能建议](https://developer.android.com/develop/ui/compose/performance/bestpractices)。

Compottie 提供跨平台 Lottie 渲染器，以及较小的 lite 版本和资源加载模块；不同 Lottie 特性仍需实际资源验证。项目 minSdk 24，若使用其 dot/network 模块需要检查 desugaring 配置。[项目说明](https://github.com/alexzhirkevich/compottie)。Android Shader 的平台门槛来自 [AGSL 官方说明](https://developer.android.com/develop/ui/views/graphics/agsl)；Rive 的接入方式参考 [运行时文档](https://rive.app/docs/runtimes/getting-started)。

这些图形效果不依赖视觉模型的 GPU/NPU 加速：UI 绘制和神经网络推理是不同链路。Canvas 粒子模拟仍有 CPU 成本，透明叠层和发光也有绘制成本，不能据此承诺无发热。

## 创意场景候选

下列时长均为设计建议，尚未接入现有行为规则。

| 场景 | 演出与惊喜点 | 建议时长 / 触发 |
| --- | --- | --- |
| V 字庆祝 | 猫脸先兴奋一下，两侧小光点升起，在额头上方绽放；最后落下少量 🎉 / ✨ | 3–4 秒；已确认的 V 字或庆祝指令 |
| 被夸奖 | 一颗小 💛 从脸侧探出，迟疑一下，再带着两颗小心心飘走；猫脸害羞 | 2–3 秒；“你真可爱”“你很棒”等确认文字 |
| 点赞奖励 | 先冒出一颗星星，随后出现很短的金色光环，像获得一个小奖励 | 1.5–2 秒；已确认点赞；适合高频轻回应 |
| 小雨变晴 | ☁️ 进入画面边缘，少量雨滴落下，随后云散、出现一点 ✨；情节落点是陪伴与舒缓 | 4–6 秒；明确的难过话语、情景指令或手动预览；不因一帧难过外观就自动大面积下雨 |
| 惊讶小泡泡 | 小 🫧 / 自绘气泡从两侧升起，一颗靠近耳边位置轻轻破掉；猫脸好奇 | 2 秒；惊讶或发现有趣事物的确认事件 |
| 调皮躲闪 | 捏合后出现小星点，猫脸短暂眨眼，星点像被“捏走”一样消失 | 1.5 秒；捏合事件；使用已有眨眼表情配合 |
| 晚安流星 | 猫脸慢慢安静，一颗流星划过上方，留下两三颗星星后渐隐 | 4 秒；“晚安”；降低亮度，不长时间循环 |
| 轻哼音符 | 🎵 从嘴附近冒出，沿小弧线移动；音符出现节奏与实际播放状态配合 | 2–3 秒；未来哼唱/音乐场景，当前不根据普通说话伪造音乐节奏 |

创意原则：同一场景可有两三种配色、轨迹或符号变体，由受控随机种子选择；重要动作和含义保持一致。惊喜来自短暂的铺垫、出现位置和收尾，而不是每次识别都全屏播放动画。

第一批建议先做：烟花庆祝、爱心漂浮、小雨变晴、星光奖励。这四项覆盖爆发、上浮、连续落下和短脉冲，足以验证核心引擎和符号图层。

## emoji 与文字符号策略

Android Compose 的 Text 有 emoji 支持，但跨 Android、iOS 和桌面的字形、颜色和新 emoji 覆盖取决于字体及平台。第一版优先少量常见符号，并在三端检查显示。复杂 emoji 是完整的 Unicode 序列，不能按 Kotlin Char 拆成粒子。[Android emoji 支持](https://developer.android.com/develop/ui/compose/text/emoji)、[Unicode emoji 规范](https://unicode.org/reports/tr51/)。

每个符号粒子保存完整字符串，如 `"💛"` 或 `"☁️"`。新符号不支持时应可替换为自绘圆点、星星、爱心，避免显示缺字框。若后续需要完全统一的视觉风格，可在同一符号接口后接本地 SVG/PNG 或自绘图形。Twemoji 是资源候选，其图形采用 CC-BY 4.0，应随资源保留署名信息；本次调研没有下载或使用这些资产。[Twemoji 项目](https://github.com/jdecked/twemoji)。

建议分开两种粒子：几十个烟花/雨滴用 Canvas 批量绘制，几颗较大的 emoji 用独立符号层；不要用上百个 Text 组件模拟雨滴。现有霓虹猫脸可用金色、青色和少量彩色符号搭配，控制每帧的大面积发光。

## 模块与事件设计

建议模块包含：

- `model`：EffectId、EffectRequest、强度、时长、锚点、随机种子、图层顺序。
- `engine`：粒子状态、发射器、解析运动轨迹、生命周期、暂停和清理。
- `render`：Canvas 粒子绘制、符号绘制、图标/动画资源适配器。
- `ui`：EffectLayer、特效预览页、开关与强度控制。

`lib_effects` 不采集音视频、不调用大模型，也不决定什么情绪该播放什么。`lib_behavior` 在行为被确认接受时发出特效意图，shared 将其交给特效控制器。表现模块之间保持独立，触发协议只包含纯数据。

建议请求字段：instanceId、effectId、startedAt、duration、intensity、anchor、seed。触发依据为确认后的事件 ID，不订阅每帧相同的识别结果来重复播放，也不把“开心表情保持了三秒”当成三次新事件。完整 emoji 字符串是符号定义的一部分。

第一版使用屏幕相对坐标（0–1），并让宿主提供可绘制区域、眼睛/嘴巴保护区域和控件避让区域。贴脸特效需跟随猫脸上移、缩放和倾斜；天气类效果可以锚在屏幕上。现有 FaceMetrics 能提供基础几何，但还需考虑 FaceParams 的动态变换。

## 播放规则与性能预算

- 默认每次最多一个主要情景，可带少量辅助符号；新效果根据优先级替换或合并，不无限堆叠。
- 视觉分类需连续确认；最终语音含义可触发。清晰语义事件可优先于弱视觉线索。
- 同一事件只播放一次，设置独立特效冷却；与主动开口冷却分开。取消、离开猫脸页或后台时释放效果。
- 倾听时优先轻微星光/爱心等；思考和说话时降低密度，保持嘴部和语音控件清楚。
- 雨滴、彩纸、符号图层不处理点击，HUD、相机入口和停止回复按钮位于其上层。
- 建议初始预算：手机和小屏 30fps，最多约 60–120 个简单粒子或 8–16 个符号；这是调试起点，不是已验证的性能指标。
- 无效果时停止帧循环；预分配粒子、缓存图形与文字布局，避免逐帧新建大量对象。减少大面积透明模糊和离屏合成。
- 同时运行视觉推理时做压力测试；可按帧耗时降低粒子数量和发光，而不降低交互响应优先级。

## 落地与验收

先搭透明层、请求协议、生命周期和预览入口，再做四个基础情景与 emoji 层，最后接入 V 字、点赞、被夸奖和明确情绪话语。不要第一步就让全部表情自动触发效果。

验证需要覆盖：事件去重、到期恢复、优先级、取消和后台清理；固定 seed 下的分时刻图像走查；小屏/手机/桌面上的坐标和控件避让；不同平台 emoji 的缺字/风格；与视觉推理同时运行的帧时间、持续温升和内存。Lottie、Shader、复杂剧情动画在基础版本验证后再接入。
