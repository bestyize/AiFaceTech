# 表情页语音控件

表情页进入“对话”后使用无描边、无外圈光晕的浅炭黑胶囊，猫脸上移 24 dp，留出底部操作空间。默认保留猫脸的开关仍由声音设置控制。

- 点击待机控件开始说话；分段语音录音中再次点击结束并提交。
- 分段识别、思考和合成期间不能重复开始录音，但可以长按查看记录。
- 流式回复从生成文字起就可以点击“停止回复”，同时取消文字生成、合成和播放；实时模式点击结束整个实时会话。
- 长按任何状态展开完整对话记录，点击“收起”回到猫脸；点击“返回”退出对话。
- 识别后未配置 AI 大脑、生成回复后未配置在线朗读，以及报错时，保留文字和完整提示，胶囊显示“查看文字 / 查看回复 / 查看提示”，点击展开。

布局使用可用 dp 尺寸和系统字体缩放，不直接用屏幕物理像素决定断点。可用宽度除以字体倍率小于 400 dp，或高度除以字体倍率小于 220 dp 时采用紧凑布局；触摸区至少 48 dp 高。

320×240、密度 1 的屏幕显示麦克风和短状态，控件约 148×48 dp。800×480、密度 1 的屏幕显示完整状态、轻量活动动画和操作提示，控件约 320×72 dp。高密度屏的物理像素尺寸随系统密度变化。活动动画表达聆听 / 处理 / 回答状态，不是实测音量。

状态由语音流程显式更新：录音 → 识别 / 首句生成与合成 → 播放 → 待机。首块音频进入播放后保持“回答中”，后续文字与音频并行产生。原来的 `VoiceVisualState` 回调保持兼容。

## 离线验证

在 `HappyFaceAi` 目录运行：

```text
gradlew.bat :desktopApp:exportVoiceFaceControls
gradlew.bat :shared:jvmTest :androidApp:assembleDebug
```

截图导出至 `desktopApp/build/voice-face-controls`。导出器使用真实 Compose 控件和猫脸渲染，覆盖两种目标分辨率、1.5 倍密度、1.5 倍字体、手机横屏和竖屏；验证触摸尺寸、文字溢出、开始 / 结束、处理期间防重复、记录展开 / 收起以及错误和仅识别文字的入口。验证不读取密钥、不启动麦克风、不请求在线服务；硬件上的收音、朗读和触摸体验需另行实测。
