# 生命中心页面验收清单

用于防止本地 AI 只“定义结构”却没有真正实现。

## A. 工程
- [ ] 现有工程可以打开
- [ ] Gradle Sync 成功
- [ ] Build 成功
- [ ] App 可启动
- [ ] 没有另建无关工程

## B. 首页
- [ ] 沉浸式表情首页仍然存在
- [ ] 没有传统底部 TAB
- [ ] 长按或明确入口可以进入生命中心
- [ ] 返回首页正常

## C. 生命中心
- [ ] 页面是真实实现，不是截图
- [ ] 横屏正常
- [ ] 左侧有角色资料
- [ ] 右侧有功能卡片
- [ ] 有最近变化
- [ ] 有进入陪伴 / 返回全屏
- [ ] 无明显溢出

## D. 八个入口必须可点
- [ ] AI 大脑
- [ ] 声音
- [ ] 人格
- [ ] 记忆
- [ ] 表情与外观
- [ ] 能力
- [ ] 生活节律
- [ ] 设备与系统

未完成详情可以进入 Placeholder，但不能无响应。

## E. 表情页
- [ ] 表情与外观能进入现有表情页
- [ ] 能返回生命中心
- [ ] 没有复制第二套表情系统

## F. 自适应
- [ ] 宽屏左右双栏
- [ ] 窄屏不崩溃
- [ ] 文本不过度裁切
- [ ] FeatureGrid 可扩展

## G. 代码质量
- [ ] 不是单个巨型 Composable
- [ ] Feature 数据驱动
- [ ] UI State 与 UI 分离
- [ ] Route 与 Screen 分离
- [ ] 样式 Token 统一

## H. 真实性
没有真实接入时，不允许写“已完成”：
- 大模型 API
- TTS
- 长期记忆
- Skills
- 硬件设备管理

## I. 最终体验
打开 App 后应该仍然感觉：
> “我在和一个小生命相处。”

而不是：
> “我进入了一个 AI 设置工具。”
