# 生命中心页面设计包（完整版）

用于交给本地 AI / 本地开发助手继续实现 AI 小生命 App 的「生命中心」。

## 文件
- `生命中心页面设计说明.md`：页面定位、视觉与横竖屏策略
- `01_本地AI开发提示词_强约束版.md`：可直接复制给本地 AI
- `02_Compose页面结构与组件说明.md`：工程与组件拆分建议
- `03_信息架构与交互流程.md`：首页 → 生命中心 → 详情页
- `04_完整页面清单与路由.md`：页面、路由与未来扩展
- `05_验收清单.md`：检查本地 AI 是否真正完成
- `assets/生命中心_横屏设计稿.png`：当前设计稿

## 核心原则
> 首页负责“让用户感受到生命”，生命中心负责“让用户理解并管理这份生命”。

不要把首页改成传统 AI App，不要加传统底部 TAB。生命中心是所有新增能力的统一入口。
