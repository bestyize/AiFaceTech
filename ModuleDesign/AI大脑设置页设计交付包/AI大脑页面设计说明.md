# AI 大脑独立设置页设计说明

## 1. 页面定位

路径：

生命中心
→ AI 大脑

这是独立设置页。

目标：

让用户理解：
- 当前使用什么大脑
- 可以切换哪些模型
- 如何连接自己的 AI 服务
- AI 具备哪些能力

不是普通 API 管理页面。

---

# 2. 页面整体结构

采用横屏优先布局：

```
┌───────────────────────────────────┐
│ 返回    AI 大脑          返回生命中心 │
├──────────────┬────────────────────┤
│              │ 模型提供商          │
│ 当前大脑      │ 模型选择            │
│              │ 能力接入            │
│ 思考模式      │ 密钥配置            │
│              │                    │
└──────────────┴────────────────────┘
```

---

# 3. 左侧区域

## 当前大脑

显示：

- 当前厂商
- 当前模型
- 模型特点标签

示例：

DeepSeek · DeepSeek-V4-Pro

标签：

- 深度思考
- 中文友好
- 高性价比

注意：

这里是展示，不是配置。

---

## AI 小生命状态展示

保留角色元素：

- 小猫脸部
- 当前表情
- 一句话陪伴文案

目的：

避免页面变成冷冰冰的开发工具。

---

## 思考模式

三个选项：

### 快速

适合：
- 简单问答
- 日常交流

### 平衡

适合：
- 默认模式
- 日常推荐

### 深度

适合：
- 复杂任务
- 推理分析

---

# 4. 右侧区域

## 模型提供商

横向滑动卡片。

固定内置：

1. DeepSeek
2. 智谱
3. Kimi
4. MiniMax
5. 自定义

要求：

- 卡片可横划
- 当前选中高亮
- 支持未来增加供应商

---

## 模型选择

根据供应商动态加载。

规则：

- 默认最多显示 5 个推荐模型
- 支持横向滑动查看更多
- 最后一个永远是「自定义」

模型数据应该来自服务端或配置文件。

不要写死。

---

## 能力接入

模块：

- 联网搜索
- 长期记忆
- 工具调用
- 日程与提醒

使用 Switch。

---

## 密钥配置

原“连接与高级设置”改名。

只包含：

- API Base URL
- API Key
- Model

默认使用 OpenAI Compatible 格式。

不包含：

- temperature
- timeout
- 其它模型参数

原因：

这些属于高级模型策略，不应该污染普通配置。

---

# 5. 删除内容

以下内容不要出现：

- 大脑状态栏
- 温度设置
- 超时设置
- 复杂参数调节

---

# 6. 交互原则

## 模型提供商

点击：

切换供应商

↓

刷新模型列表


## 模型选择

点击：

切换当前模型


## 密钥配置

点击：

进入编辑

保存：

测试连接

成功：

更新当前大脑

---

# 7. 视觉规范

保持生命中心风格：

- 深色背景
- 暖金高亮
- 大圆角卡片
- 轻玻璃效果
- 柔和阴影

不要：

- 工程后台风
- 表格风
- 密集参数列表

---

# 8. 未来扩展

预留：

- 本地模型
- 私有服务器
- 多 Agent 大脑
- 模型自动切换
- 成本控制
- 使用统计
